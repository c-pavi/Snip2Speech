Release notes

This build focuses on stability and correctness. We fixed a crash that happened when opening a document from a network volume that disconnected in the middle of a read. Scrolling in long lists is smoother on older hardware, and the export dialog now remembers the last folder you used.

  • Several rare memory leaks were closed
  • Keyboard shortcuts work again in the preview window
  • Large paste operations no longer freeze the editor
  • Localization was refreshed for twelve languages

As always, thank you for the detailed bug reports. They make a real difference and most of the fixes above came directly from them.
